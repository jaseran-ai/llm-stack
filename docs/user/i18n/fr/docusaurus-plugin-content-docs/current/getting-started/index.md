# Prise en main de la Stack LLM

Bienvenue dans le guide utilisateur de la **stack LLM**. Cette section fournit tout le nécessaire pour déployer et utiliser votre plateforme d'IA personnelle en quelques minutes.

---

## Qu'est-ce que la Stack LLM ?

La stack LLM est une plateforme d'IA d'entreprise complète et auto-hébergée offrant :
* Une interface web de chat moderne (**Open WebUI**) avec bases de connaissances documentaires (RAG) et recherche web privée.
* Une passerelle de modèles unifiée et équilibrée (**LiteLLM**) supportant les modèles locaux et cloud.
* Des garde-fous de confidentialité intégrés (**Betterleaks + Presidio**) biffant automatiquement les secrets et PII.
* Un Single Sign-On (**Authentik**) protégeant tous les services par contrôle d'accès basé sur les rôles (RBAC).
* Une observabilité complète (**Langfuse**, **Prometheus**, **Grafana**) traçant les prompts, latences et coûts en tokens.
