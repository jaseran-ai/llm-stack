# Notes de version : v1.0.0 — Première version publique

* **Date de publication** : 2026-10-19
* **Tag Git** : `v1.0.0`

---

## Points clés

### 1. Plateforme LLM privée sur une seule machine
* Ollama avec un modèle CPU intégré, LiteLLM comme passerelle compatible OpenAI, et Open WebUI avec RAG Qdrant et recherche web privée SearXNG.
* Traçage et analytique Langfuse adossés à PostgreSQL, ClickHouse, Redis et SeaweedFS S3.

### 2. Identité unifiée
* Authentik comme fournisseur d'identité unique, configuré par trois niveaux de blueprints déclaratifs : identité de base et groupes RBAC, fournisseurs proxy Forward-Auth avec l'outpost intégré, et applications OIDC natives.

### 3. Secrets et confidentialité
* HashiCorp Vault KV v2 avec des secrets rendus dans un tmpfs en mémoire, jamais écrits sur disque persistant.
* Rédaction des secrets et données personnelles par Betterleaks pour LiteLLM et Open WebUI, avec tokenisation réversible AES-256-GCM adossée à Redis.

### 4. Réseau durci
* Traefik v3 avec en-têtes de sécurité et TLS interne, bases de données isolées sur un réseau Docker interne.
* Trois modes DNS : `/etc/hosts`, CoreDNS intégré, ou tunnel Cloudflare Zero Trust provisionné par Terraform (DMARC strict, CAA, TLS 1.2+).

### 5. Observabilité
* Prometheus, Alertmanager, tableaux de bord Grafana, logs Loki et Vector, sondes Gatus et Dozzle.
