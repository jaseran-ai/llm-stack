# Tutoriels

Les tutoriels sont des guides pratiques orientés apprentissage conçus pour vous accompagner pas à pas dans l'accomplissement d'un flux de travail complet sur la stack LLM.

---

* [**Tutoriel 1 : Ajouter une Nouvelle Application à la Stack**](add-an-application.md)
  Découvrez le processus standard en 7 étapes pour déclarer un nouveau service dans Docker Compose, configurer ses secrets, intégrer le SSO Authentik et ajouter une sonde de santé Gatus.

* [**Tutoriel 2 : Consommer l'API LLM avec Python et cURL**](consume-api.md)
  Apprenez à vous authentifier auprès de la passerelle unifiée LiteLLM, soumettre des complétions et vérifier la biffure automatique des données personnelles (PII).
