# Guides Pratiques (How-To)

Les guides pratiques sont des fiches opérationnelles orientées objectif pour accomplir des tâches d'administration et d'utilisation précises.

---

* [**S'authentifier via le SSO Authentik & Gérer les Rôles**](authenticate-sso.md)
  Découvrez comment vous connecter, utiliser le Forward-Auth et assigner des utilisateurs aux groupes RBAC `admins` ou `users`.

* [**Exécuter des Sauvegardes Chiffrées & des Restaurations Ciblées**](backup-and-restore.md)
  Apprenez à exécuter des sauvegardes atomiques chiffrées (`backup.sh`) et des restaurations d'urgence (`restore.sh`).

* [**Configurer la Recherche Web dans Open WebUI**](configure-web-search.md)
  Activez la métarecherche SearXNG pour ancrer les réponses du chat dans des faits réels récents.

* [**Inspecter les Prompts et les Traces d'Exécution dans Langfuse**](monitor-traces.md)
  Surveillez les latences LLM, la consommation de tokens et les arbres d'exécution de vos requêtes.
