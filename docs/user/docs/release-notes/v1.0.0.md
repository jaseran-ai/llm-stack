# Release Notes: v1.0.0 — Initial Public Release

* **Release Date**: 2026-10-19
* **Git Tag**: `v1.0.0`

---

## Highlights

### 1. Private LLM Platform on a Single Machine
* Ollama with a bundled CPU-friendly model, LiteLLM as the OpenAI-compatible gateway, and Open WebUI with Qdrant RAG and SearXNG private web search.
* Langfuse tracing and analytics backed by PostgreSQL, ClickHouse, Redis and SeaweedFS S3.

### 2. Unified Identity
* Authentik as the single identity provider, configured through three declarative blueprint tiers: core identity and RBAC groups, Forward-Auth proxy providers with the embedded outpost, and native OIDC applications.

### 3. Secrets and Privacy
* HashiCorp Vault KV v2 with secrets rendered into a memory-backed tmpfs, never written to persistent disk.
* Betterleaks secret and PII redaction for LiteLLM and Open WebUI, with reversible AES-256-GCM tokenization backed by Redis.

### 4. Hardened Networking
* Traefik v3 with security headers and internal TLS, databases isolated on an internal-only Docker network.
* Three DNS modes: `/etc/hosts`, embedded CoreDNS, or a Cloudflare Zero Trust Tunnel provisioned with Terraform (strict DMARC, CAA, TLS 1.2+).

### 5. Observability
* Prometheus, Alertmanager, Grafana dashboards, Loki and Vector logs, Gatus health checks and Dozzle.
