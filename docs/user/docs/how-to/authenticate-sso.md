# How-To: Authenticate via Authentik SSO & Manage Roles

This guide explains how to authenticate through the central identity portal and manage role-based permissions.

---

## Accessing the Dashboard

1. Open your browser and navigate to the base domain:
   ```text
   https://authentik.${DOMAIN}
   ```
2. Enter your credentials. On a freshly deployed stack, use the administrative account (`admin`) and the password generated by `./setup.sh`.
3. Once authenticated, the **Application Dashboard** displays all tools authorized for your account.

---

## Role-Based Access Control (RBAC)

The stack enforces two primary security groups:

### 1. `admins` Group
Members of `admins` have complete visibility and access to all 16 applications, including:
* Infrastructure dashboards: Grafana, Traefik Dashboard, Dozzle, Gatus.
* Database exploration tools: CHouse UI, SeaweedFS Console.
* Administration consoles: HashiCorp Vault, Authentik Admin Interface.

### 2. `users` Group
Standard users (e.g., demo accounts `alice` and `bob`) are strictly restricted:
* Permitted application: **Open WebUI** (`chat.${DOMAIN}`).
* All administrative, database, and telemetry endpoints return `HTTP 403 Forbidden` or redirect to the login flow.

---

## Adding a User to a Group
1. Sign in as `admin` and open the Authentik Admin Interface (`/if/admin/`).
2. Navigate to **Directory** → **Users**.
3. Select the target user, click **Groups**, and attach or detach the `admins` or `users` group.
4. Changes take effect on the next session request immediately.
