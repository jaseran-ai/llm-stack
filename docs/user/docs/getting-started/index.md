# Getting Started with LLM Stack

Welcome to the **LLM Stack** user guide. This section provides everything you need to know to get your personal AI platform running from scratch in minutes.

---

## What is LLM Stack?

LLM Stack is an enterprise-grade, self-hosted, all-in-one AI platform providing:
* A modern web chat interface (**Open WebUI**) with document knowledge bases (RAG) and private web search.
* A unified, load-balanced model gateway (**LiteLLM**) supporting local and cloud LLMs.
* Integrated privacy guardrails (**Betterleaks + Presidio**) that automatically redact sensitive secrets and PII.
* Single Sign-On (**Authentik**) protecting all services with role-based access control.
* Full observability (**Langfuse**, **Prometheus**, **Grafana**) tracking prompts, latencies, and token costs.
