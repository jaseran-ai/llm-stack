## [Unreleased]

### Added
- `TLS_MODE=custom`: serve an ingress certificate signed by your own CA. `./setup.sh --tls-csr` generates an ECDSA P-256 key and CSR for `DOMAIN` and `*.DOMAIN` without touching the certificate in service; `./setup.sh --tls-mode=custom` validates the signed certificate and CA chain (key match, names, chain, expiry) and installs it.

- `make actions-security`: actionlint and zizmor security audit of `.github/` (workflows and Dependabot), also run in CI.
- `make github-harden`: applies the repository security settings (read-only default token, approval for external contributors' workflow runs, SHA-pinned actions only, secret scanning with push protection, private vulnerability reporting, Dependabot alerts) and the `main` ruleset in `.github/rulesets/main.json` (pull requests and all CI checks required, no force push or deletion).

### Changed
- CI runs on GitHub-hosted `ubuntu-24.04` runners with tools from digest-pinned images (`USE_CONTAINERS=1`); workflows use SHA-pinned actions, `permissions: {}` with least privilege per job, `persist-credentials: false`, and no expressions inside `run:` scripts. Dependabot waits 7 days before proposing a new version.
- Default bundled model is now `lfm2-1.2b-rag` (LiquidAI LFM2-1.2B-RAG via Ollama) with a 32k context window.
- The LiteLLM Presidio guardrail is scoped to the request input (`presidio_filter_scope: input`) so streamed (SSE) responses are no longer buffered.
- TLS material is split into an internal CA (Vault listener certificate) and an ingress chain (`tls.crt` + `ca.crt`), generated by `traefik/scripts/certs.sh`. In internal mode the ingress certificate is reissued when `DOMAIN` changes, and Vault now gets its certificate in ACME modes too.

### Removed
- Self-hosted GitHub Actions runner setup (`runner/`, `scripts/setup_runner.sh`): unsafe for a public repository.

### Fixed
- Fresh installs: the Vault data volume ownership fix no longer fails silently before Vault Agent has rendered the service secrets, and a failed Vault initialization stops provisioning instead of writing the error as the key file.
- Ollama's host port now uses `OLLAMA_WEBAPI_PORT` (default `12434`) instead of a hardcoded `11434`, which clashed with a host Ollama installation.

## [1.0.0] - 2026-10-19 — Initial Public Release

### Added
- **Core LLM platform**: Ollama with a CPU-friendly bundled model, LiteLLM gateway (virtual keys, budgets, Prometheus metrics, Langfuse OpenTelemetry tracing) and Open WebUI with Qdrant RAG and SearXNG private web search.
- **LLMOps**: Langfuse (web + worker) backed by PostgreSQL, ClickHouse, Redis and SeaweedFS S3, with CHouse UI for ClickHouse exploration and a scoped rollback workflow for Langfuse snapshots.
- **Unified identity**: Authentik as the single IdP, configured through three declarative blueprint tiers (core identity & RBAC groups, Forward-Auth proxy providers with the embedded outpost, native OIDC applications).
- **Secrets management**: HashiCorp Vault KV v2 seeded by `setup.sh`, with Vault Agent rendering per-service secrets into a memory-backed tmpfs (`0700`/`0600`).
- **Privacy guardrails**: Betterleaks, a Presidio-compatible secret and PII redaction service used by the LiteLLM guardrail and the Open WebUI filter, with reversible AES-256-GCM tokenization backed by Redis and an optional MCP `ExtMcp` gRPC endpoint.
- **Ingress & DNS**: Traefik v3 with security headers and internal TLS; three DNS modes (`hosts`, embedded CoreDNS, Cloudflare Zero Trust Tunnel provisioned with Terraform).
- **Observability**: Prometheus, Alertmanager, Grafana dashboards and alert rules, Loki + Vector log pipeline, cAdvisor, node-exporter, Gatus health monitoring and Dozzle.
- **Network segmentation**: databases and caches isolated on an internal-only Docker network.
- **Documentation**: arc42 architecture specification with C4 diagrams and ADRs, and a Diátaxis user guide, both in English and French.
- **Quality gates**: shellcheck, yamllint, Gitleaks, Trivy, Markdown link and startup-graph checks, script unit tests, and a containerized UAT environment; all runnable locally through the `Makefile`.
